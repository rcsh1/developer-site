<Note>本页面记录 Cobo 已永久退役的功能，用于让旧链接和书签指向说明页面而非错误页面。</Note>

## 智能合约钱包（Safe&#123;Wallet&#125;）

智能合约钱包（含 Safe&#123;Wallet&#125; 子类型）已永久退役，不再作为 Cobo 的功能提供，相关指南和 API 参考已从本站移除。

Cobo Portal 已不再提供创建或管理此类钱包的入口，WaaS 2.0 API 也不再公开 `SmartContract` 钱包类型和 `Safe&#123;Wallet&#125;` 钱包子类型。Cobo WaaS 2.0 提供三种钱包类型：全托管钱包、MPC 钱包和交易所钱包。如需开始使用，请参阅 [Cobo WaaS 2.0 API 简介](/v2_cn/guides/overview/introduction)。

## Cobo Safe 与 Cobo Argus 文档（WaaS 1.0）

WaaS 1.0 中 Cobo Safe 和 Cobo Argus 的文档已随智能合约钱包一并下线，因为二者均以接入该功能的方式进行文档化。本次变更不影响 Cobo Safe 智能合约本身，仅移除其在本站的文档。

如果您仍在使用 WaaS 1.0，建议升级到 [WaaS 2.0](/v2_cn/guides/overview/introduction)。
