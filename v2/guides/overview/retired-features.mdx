<Note>This page records capabilities that Cobo has permanently retired. It is kept so that older links and bookmarks resolve to an explanation rather than an error page.</Note>

## Smart Contract Wallets (Safe&#123;Wallet&#125;)

Smart Contract Wallets, including the Safe&#123;Wallet&#125; subtype, have been permanently retired. They are no longer offered as a Cobo capability, and their guides and API reference have been withdrawn from this site.

Cobo Portal no longer provides a way to create or manage these wallets, and the WaaS 2.0 API no longer publicly documents the `SmartContract` wallet type or the `Safe&#123;Wallet&#125;` wallet subtype. Cobo WaaS 2.0 documents three wallet types: Custodial Wallets, MPC Wallets, and Exchange Wallets. To get started with any of them, see [Introduction to Cobo WaaS 2.0 API](/v2/guides/overview/introduction).
